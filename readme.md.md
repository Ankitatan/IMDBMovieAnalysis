🎬 IMDb Movie Analysis (1920–2010)

An exploratory data analysis project exploring historical movie data using Microsoft Excel to identify patterns in movie genres, IMDb ratings, and film production across decades.

📌 Project Overview

The IMDb Movie Analysis project examines historical movie data spanning 1920–2010. Using Microsoft Excel, this project focuses on organizing data, exploring movie ratings and genre distributions, and identifying trends through structured analysis and visualizations.

The project demonstrates how spreadsheet-based analytics can help transform raw data into meaningful insights about the film industry.

🎯 Objectives

- `	`Analyze movie production trends across different decades.
- `	`Explore the distribution of movies across genres.
- `	`Investigate IMDb rating patterns in the available dataset.
- `	`Compare movie trends across historical periods.
- `	`Communicate findings using Excel PivotTables and charts.
