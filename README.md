# 🎬 IMDb Movie Analysis (1920–2010)

## 📌 Project Overview

**IMDb Movie Analysis** is a data analytics project focused on exploring movie data from 1920 to 2010 using Microsoft Excel. The project aims to identify trends in movie ratings, genres, and performance through data analysis and visualization.

## 🎯 Objectives

- Analyze historical movie data from 1920 to 2010.
- Explore movie ratings and genre distributions.
- Identify trends and patterns in the film industry.
- Summarize insights using Excel-based analysis and visualizations.

## 🛠️ Tools & Technologies

- **Microsoft Excel**
- Data Cleaning and Formatting
- Data Analysis
- PivotTables and Charts

## 📊 Key Analysis Areas

- Movie trends across different decades.
- Distribution of movies by genre.
- IMDb ratings and rating patterns.
- Historical changes in movie production and performance.
