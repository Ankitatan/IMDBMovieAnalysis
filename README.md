# 🎬 IMDb Movie Analysis (1920–2010)

An exploratory data analysis project examining historical movie data using Microsoft Excel to understand trends in film genres, IMDb ratings, and movie production across decades.

## 📌 Project Overview

The **IMDb Movie Analysis** project explores historical movie data spanning 1920–2010. Using Microsoft Excel, the project focuses on organizing movie records, examining patterns in ratings and genres, and presenting findings through structured analysis and visualizations.

The goal is to demonstrate how spreadsheet-based data analytics can transform raw movie data into meaningful insights about the film industry.

## 🎯 Project Objectives

- Explore changes in movie production across different decades.
- Examine the distribution of movies across genres.
- Investigate patterns in IMDb ratings.
- Compare movie-related trends across historical periods.
- Present findings through Excel-based summaries, PivotTables, and charts.

## 🛠️ Tools & Technologies

- **Microsoft Excel** — data exploration and analysis
- **Data Cleaning** — organizing records and checking data consistency
- **PivotTables** — summarizing and comparing movie attributes
- **Charts & Visualization** — communicating patterns and trends
- **Exploratory Data Analysis (EDA)** — investigating relationships and distributions

## 🔍 Key Analytical Questions

This project is structured around the following questions:

1. How does the number of movies vary across decades?
2. Which genres appear most frequently in the dataset?
3. How are IMDb ratings distributed across the available movies?
4. Do rating patterns differ across genres or historical periods?
5. What broader patterns can be identified in the available historical movie records?

*The questions above describe the analytical scope; conclusions should be added only after verifying the results in the workbook.*

## 📊 Analysis Workflow

The project follows a structured data analysis workflow:

1. **Data inspection:** Review the available columns, record counts, and data types.
2. **Data preparation:** Check for missing values, duplicate records, inconsistent formatting, and invalid entries where applicable.
3. **Exploratory analysis:** Summarize movie records by decade, genre, and rating.
4. **Visualization:** Use suitable charts and PivotTables to compare distributions and trends.
5. **Interpretation:** Document findings supported by the analyzed data.
